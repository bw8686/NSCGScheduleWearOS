# NSCGSchedule Wear OS

A companion Wear OS application for the NSCGSchedule app, providing glanceable timetable information and upcoming class alerts on your wrist.

## Overview
- Displays current and upcoming lessons directly on Wear OS smartwatches.
- Syncs timetable context and notifications with the paired Android device.

## Prerequisites
- Android Studio with Android SDK Platform for Wear OS.
- A physical Wear OS device or Wear OS emulator.

## Building
Use Gradle to build the debug or release package:

```bash
./gradlew assembleDebug
```
